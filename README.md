\# One-Step HALT: Few-Shot Seagrass Classification



\## Overview



This repository contains the implementation of One-Step HALT, a confidence-guided framework for few-shot seagrass image classification.



The project explores how confidence-guided pseudo-labeling can improve classification performance when only a limited number of labeled training samples are available.



\## Research Areas



\- Few-Shot Learning

\- Computer Vision

\- Deep Learning

\- CLIP-based Feature Extraction

\- Confidence-Guided Pseudo-Labeling

\- Seagrass Image Classification
